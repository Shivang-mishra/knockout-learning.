# Knockout Learning

A beginner-to-intermediate learning project demonstrating [Knockout.js](https://knockoutjs.com/) MVVM (Model-View-ViewModel) patterns.

## Features Covered
- **Observable Properties & Two-way Data Binding**: Binding input elements with `value` and `valueUpdate: 'input'`.
- **Observable Arrays**: Managing dynamic lists of data (`observableArray`).
- **Templating with `foreach`**: Rendering tabular employee records.
- **Context Properties (`$parent`)**: Deleting individual items from within a `foreach` loop.
- **Dynamic Count**: Dynamically displaying total array length reactively.
- **Validation & Reset**: Trimming input, checking empty states, and resetting observables.

## Project Structure
- `index.html`: Introduction to Knockout.js observables and two-way binding.
- `index2.html`: Employee Management System with observable arrays, adding/deleting employees, and reactive count.
- `knockout-3.5.3.js`: Knockout.js core library.
